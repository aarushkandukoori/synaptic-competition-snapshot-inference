# Inferring Synaptic Competition Dynamics from Static Connectomic Snapshots: A Simulation-Based Inference Framework

> **Early-stage research proposal** — we are actively seeking expert feedback.
> Project page: https://aarushkandukoori.github.io/synaptic-competition-snapshot-inference/

An early-stage plan to infer synaptic competition parameters from static multi-age connectomic snapshots using simulation-based inference on synthetic data.

**Authors:** Aarush Kandukoori (Carnegie Mellon University, Lead Student Author) ·
Aditya Kandukoori (Poolesville High School, Co-Author)

## ⚠️ Status & AI assistance disclosure

This repository accompanies a **proposal**, not a completed study. **No experimental
results are claimed.** All datasets here are **synthetic/mock**, generated by
`data/generate_synthetic.py`, and exist only to make the proposed framework runnable
end-to-end. AI tools (Claude) were used for literature synthesis, ideation, and draft
preparation; an AI review checked the draft before release, and the authors take responsibility for all content. The same
disclosure appears in the proposal's abstract and methodology.

## Reproducing

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python data/generate_synthetic.py
python -m src.run_demo
```
